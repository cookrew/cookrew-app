ONE-PRODUCER GUARANTEE

  • • at most one producer per conversation at any instant, enforced at the byte
  • • owner composing → dispatch 409 / delivery cancels ("owner took the input box")
  • • dispatch delivering → owner bytes refused (visible toast), never interleaved
  • • no takeover past the irreversible boundary — refuse, never displace
  • • survives detach AND app restart (WAL-backed provenance)

CONCURRENCY = FLEET WIDTH

  • • one in-flight dispatch per agent (409 busy; replay always 200)
  • • N agents run N dispatches in parallel — no caps, no scheduler modes
  • • consumer plane (v5.1): instances of team templates, never owner agents
  • • idle fleet costs zero: tracking derives from work, drains itself

CLOSURE EVIDENCE STACK

  • • parser finality: end_turn / task_complete / stopReason (corpus-verified)
  • • identity: exact delivered bytes, sufficient because producers serialize
  • • status may HOLD a turn open, never close one; timeouts never outrank rows
  • • outcome channel: done | failed | interrupted (parser > infrastructure)
